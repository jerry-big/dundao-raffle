# 断刀 · 锻刀大会

一个用「锻刀」包装的移动端 H5 抽奖小游戏：选刀身 / 刀柄 / 护手，一锤一锤敲，按锻打次数结算品质与分数，全场排名发奖。

**在线试玩：** https://37jbmgdf5e5whi908av.traesite.cn

## 玩法

1. 自选刀身、刀柄、护手各一件，只决定刀的轮廓，不影响数值。
2. 每点一次「落锤」落一锤，分数 +4,000，刀身随锤数由暗烧红。
3. 锻打次数在入炉时由系统定死、对玩家保密，敲到第 N 锤自动成刀。
4. 次数决定品质：废铁 / 粗胚 / 凡品 / 良品 / 精品 / 名品 / 神品。
5. 分数越高，成刀后的材质、刃纹、装饰与光效越豪华，最高 100,000 分。

## 计分

```
总分 = 锻打次数 × 4,000 + 品质加成 + 余烬
锻打次数 12–24，品质加成 0–4,000，余烬 0–9
```

24 锤神品 = 100,000 分。

## 本地运行

直接双击 `web/index.html`，或在目录内起一个静态服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/web/
```

用手机访问时，建议把浏览器切到设备模拟或直接部署后打开。

## 状态说明

当前为纯前端 Demo：分数、次数、编号都在浏览器内生成，刷新即丢，不具备「一人一次」与排名能力。

要用于真实活动，需要补服务端：

- 微信网页授权换 openid，数据库唯一索引保证一人一局
- 服务端生成锻打次数与分数，前端只负责动画
- 排行榜、锁榜结算、获奖名单导出

产品方案见 [docs/product-plan.html](docs/product-plan.html)，第 05–06 节写明了接口与规则。
